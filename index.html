MCU 0115 Mi6-V2 ALLMODES10 · ONE-PASS stage → commit → reboot → verify
Этот canary НЕ повышает скорость. Он построен по Mi6 V2 path BW-Patcher, а не старой упрощённой DUAL10-подмене.
