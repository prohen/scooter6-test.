Xiaomi Scooter 6 — ACTION 6.1 diagnostic v1.0

Action-only диагностика

Страница делает только подтверждённый AUTH, читает MCU через 001C op=1, проверяет 2.8 RIDING_ACTIVE=false и после ручной фразы подтверждения отправляет один SPEC ACTION: Service 6 / AIID 1.

ACTION не повторяется автоматически даже при запросе transport resend. После него страница только повторно читает MCU через 0,5 и 3 секунды. DFU/firmware transport здесь отсутствует. LTMK не сохраняется и не выводится в лог.

LTMK / Scooter Link export code
Не отправляй LTMK в чат. Вставляй его только сюда. Поддерживается и код Export из Scooter Link.
