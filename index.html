Xiaomi Scooter 6 — Safe SET Probe v1.1

Что делает v1.1

Проходит подтверждённую BLE-аутентификацию и тестирует настоящий MIoT SET на одном обратимом параметре: 4.4 TAIL_LIGHT_IS_ON.

Безопасный первый тест: сначала GET текущего значения, затем SET того же самого значения (например false → false), затем повторный GET для проверки. То есть эта версия не включает и не выключает фонарь; она только подтверждает сам механизм записи. Никакие другие свойства не изменяются.
